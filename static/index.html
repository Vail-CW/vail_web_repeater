How It Works

Welcome to the Weekly Enigma Challenge! A new encrypted message starts each Sunday morning using World War II-era Enigma machine settings - tune in anytime during the week to decode it!

  1. Listen to the morse code message being transmitted (it loops every few seconds)
  2. Copy down the encoded letters you hear
  3. Use an Enigma simulator (like cryptii.com) with the settings shown below
  4. Enter your copied text into the simulator to decode it
  5. Remove any spacing characters (like "X" between words) from the decoded message
  6. Submit your answer below to get on the leaderboard!

Tip: The message may use "X" to separate words. Remove these before submitting your answer.
